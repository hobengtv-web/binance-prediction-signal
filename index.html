HOW TO READ & ACT ▾

Binance Prediction: win UP if price at end of round ≥ open (LOCK); win DOWN if < LOCK. Ties are usually refund.

Sinyal 2 detik: arah dibentuk dari 2 detik pertama sesi (harga vs LOCK), lalu digrade oleh tier: STRONG / GOOD / FAIR. Nilai ambangnya berasal dari profil gate yang aktif (dilonggarkan/diketatkan learner tanpa deploy).

AMBANG AKTIF (dari server, mode —): memuat…

Play utama (terukur): harga pada 2 detik hampir selalu kembali menyentuh LOCK (79% pada sinyal ter-gate; turun seiring besarnya jarak/gap). Jadi mean-reversion: entry contra-lock, exit di LOCK — bukan menebak arah akhir sesi (di 2 detik hanya ~54–57%).

Exit (terukur): jual-di-lock win ~86% · ladder 40% lock / 30% +0.02% / 30% trail puncak-halus win ~70% dengan capture ~8× lebih besar · menahan sampai settle akhir sesi hanya ~43% — jangan.

PEAK / ZONE / MOMENTUM / RSI: PEAK = titik ekstrem harga sesi (▲ atas / ▼ bawah). ZONE = harga pada ekstrem itu. MOMENTUM = arah slope. RSI 5m >70 overbought, <30 oversold. Ini konteks bantu, bukan sinyal utama.

REWARD = jarak harga sekarang ke LOCK dalam % (potensi hasil bila lock tersentuh). Makin jauh dari lock makin besar rewardnya — tapi peluang tersentuhnya makin kecil (lihat baris TOUCH LOCK di REASON).

TREND = arah 3 sesi terakhir yang selesai (BULLISH/BEARISH/FLAT) sebagai konteks/bias, bukan penentu arah sinyal.

MODE = alasan sinyal begini: TREND (lolos gate) · LOWVOL (volume di bawah ambang FAIR aktif) · FILTERED (tidak lolos tier/ambang) · LATE (lewat batas telat profil gate) · NO-LIQ (pasar terlalu sepi) · WARMUP (data 2 detik belum lengkap) · LEARN-BLOCK (ditahan oleh pelajaran learner).

CONFIDENCE = skor keyakinan tampilan (pola candle + RSI + momentum + likuiditas + faktor kelayakan). Ini indikator bantu; yang mengikat adalah tier + ambang gate dan hit rate terukur yang tertulis di REASON.

Tab SIGNAL / UP / DOWN: SIGNAL = keyakinan mengikuti sinyal 2 detik yang aktif; UP/DOWN = paksa tampilan untuk arah itu (untuk memantau skenario arah lawan).

DESKTOP SIGNAL ACCURACY: riwayat sinyal desktop (hijau benar / merah salah). Tombol reset hanya menghapus riwayat tampilan di browser ini — ledger belajar di server tidak terhapus.

Learner (tanpa AI): setiap sesi — termasuk yang ditolak gate — direkam beserta hasilnya. Re-fit harian menyesuaikan konteks (bucket + Wilson bound) dan ambang (coordinate ascent memaksimalkan Wilson lower bound), dinilai walk-forward (70% data awal untuk latih, 30% paling akhir untuk uji). Model hanya menggantikan yang berjalan bila menang pada jendela uji, dan setiap keputusan tercatat beserta alasannya. Pantau di panel STATUS LEARNER. Balik ke ambang konservatif: env server GATES_MODE=strict.

SUARA NOTIFIKASI: browser memblokir audio sampai ada interaksi pertama. Klik sekali di halaman (atau tombol 🔇 suara di header) untuk mengaktifkan — indikator berubah menjadi 🔊 suara. Selama masih 🔇 alarm tetap berjalan secara visual (kartu coin berkedip/glow) tetapi tanpa bunyi.

Cara pakai: (1) baca AMBANG AKTIF untuk tahu sedang mode bootstrap (longgar) atau ambang hasil belajar; (2) tunggu Recommendation: UP/DOWN (sinyal lolos gate) dan ikuti TRADE ASSISTANT untuk entry/exit; (3) entry contra-lock: tunggu harga di sisi BERLAWANAN dari LOCK (rek UP -> harga di bawah LOCK lalu BELI; rek DOWN -> di atas LOCK lalu JUAL); (4) exit sesuai instruksi (JUAL DI LOCK / LADDER / TRAIL) — jangan menahan sampai settle; (5) cek STATUS LEARNER untuk progres data & ambang yang dipakai.
