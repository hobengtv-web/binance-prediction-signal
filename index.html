HOW TO READ & ACT ▾

Binance Prediction: win UP if price at end of round ≥ open (LOCK); win DOWN if < LOCK. Ties (exact same) are usually refund.

MOBILE PREDICTION: panel above (LOCK PRICE, PREDICTION, CONFIDENCE, PRICE, DELTA, MODE) gives early signal based on first 1s candle + pattern analysis of 30 previous sessions. Prediction is computed once per session and locked until the session ends — it does not change every tick.

SIGNAL sync: on SIGNAL tab (confMode = SIGNAL), the signal direction (UP/DOWN) and confidence LED bar direction are locked to the mobile prediction. On UP/DOWN tabs, signal uses realtime price action (counter-trend). Confidence values (%) remain realtime on all tabs — only direction is locked on SIGNAL tab.

Entry focus: 5m → last 2 minutes, 15m → last 5 minutes, 1h → last 10 minutes. Outside the window, confidence is lower.

PEAK / inflection: find price extremum (▲P top / ▼P bottom) within window. This is the core strategy — we FADE (counter) the peak so that at close we get larger reward: top peak → predict DOWN, bottom peak → predict UP.

REWARD = estimated % movement from PEAK price to projected close (larger = more worth fading).

ZONE TOP/BOTTOM = price at extremum (reversal candidate). MOMENTUM = slope direction. RSI 5m >70 overbought, <30 oversold.

TREND = direction of 3 most recent completed sessions (BULLISH / BEARISH / FLAT) used as trend bias — affects CONFIDENCE & signal filter. % = trend strength/age: longer consecutive candles in same direction → higher %; detected reversal (peak against trend direction) → % drops.

MODE: REVERSAL↑/↓ = we fade the peak (top→DOWN, bottom→UP); CONT = follow trend; CLOSE = last 20 seconds, use current price vs LOCK (most decisive).

CONFIDENCE = confidence level for chosen direction. Computed from: candle pattern (2-3 candle confirmation post-peak) + indicators (RSI, z-score, momentum, 3-session TREND, liquidity) — then multiplied by feasibility factor: chance price reaches target (LOCK/OPEN) within remaining time. Closer to deadline & further price drifts from LOCK (against chosen direction) → confidence decreases. Always active & realtime.

CONFIDENCE MODE: SIGNAL = auto counter-trend (UP when price down, etc). Pick UP/DOWN to force confidence display in that direction — e.g. TREND 3 sessions BEARISH → pick DOWN, wait for price to rise forming a peak, then DOWN confidence rises as entry confirmation. Source indicator adjusts: WITH trend → calculated from 3 PREVIOUS SESSIONS (proof trend continues); AGAINST trend → calculated from ACTIVE SESSION (old fade-peak logic). Indicator "3 SESSIONS PRIOR / ACTIVE SESSION" above shows the source.

MOBILE PREDICTION ACCURACY: panel below shows history of mobile prediction accuracy — each dot is green (correct) / red (wrong). Reset only clears accuracy data, not active prediction.

How to use: (1) monitor MOBILE PREDICTION for early signal; (2) on SIGNAL tab, signal direction & confidence LED follow mobile prediction — confidence values remain realtime; (3) wait for ENTRY WINDOW: ACTIVE; (4) check PEAK + REVERSAL + REWARD; (5) if MODE REVERSAL & high CONFIDENCE → take UP/DOWN (fade peak); (6) if NEUTRAL (no peak / wrong direction) → don't select or wait; (7) check LIVE alignment for confirmation.
